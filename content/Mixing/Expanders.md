
Essentially every dynamic processor is about volume control. The audio comes in and part of it goes through the side chain (the side chain is always working).

The side chain tells the amplifier to turn up or down. In an expander we set a **threshold** and decide that everything under it gets turned down.


### Using Expanders

**Threshold** – at what point are we turning the audio down

**Ratio** -  
- if it was a 1:1 ration – if the input is 1db below ratio, the output will be 1db bellow the threshold (no effect). 
- If it was 2:1 - if the input is 1db below ratio, the output will be 2db bellow the threshold.              
- If it was 2:1 - if the input is 1db below ratio, the output will be 100db bellow the threshold – it turns it down by 99dB. Ratio is the **strength** of the effect. As we turn the threshold way down, it becomes a gate.

**Attack** – how quickly the signal opens – fast attack – instantaneous, slow attack – slow fade in). This is because on default the gate is closed. For drums **always use fast attack**

**Release** – how long will it take to the gate to fade out.

**Hold** – the gate holds for a curtain time.


### Gates
Gates used to be used eliminate noise, but if you don’t want/need to de-noise it’s best to not use gates and keep the noise. Today they are used on drums to isolate drums and to eliminate finger noise on staccato bass.
