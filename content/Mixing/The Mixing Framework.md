**If you think about it, mixing is a form of additive synthesis**. Essentially, when mix, we add multiple waves to create a new waveform. A new waveform that’s a composite of other waveforms.

### Mixing vs Mastering
Fundamentally, mastering is about working with one track, vs working with multiple tracks in mixing. Some musicians don’t know the difference between the two, therefore it’s good to clear with your clients what they want you to do before you start the project.

### Problem solving
Mixing should be done with **intent.** That intent is about **problem solving**. Pull different tracks and ask – is this track functioning properly? If it is, we leave it alone. If not, we fix that. Then we move to the next track. Once the problem solving faze is out of the way, then we can start to do the creative stuff. We don’t add plugin unless we know what that plugin does. What problem are we fixing by adding that effect?

**Not everything in your production needs to be creative.** Half of mixing is creative, but also half of it is **functional**. Not everything needs to be creative, so ask yourself – does this element need to be functional or creative? Sometimes we mix both creative and functional. It’s about balance.


### 3 Aspects to think about when mixing

There are three things you can change if you have issues:

1. **Frequency problem** (is it too muddy? Dull?) – EQ, Distortion
2. **Dynamic range:** the difference between loud and soft – Compressor, expander, distorion
3. **Sense of space/time** – Reverb, delay

So when we have problems we should ask ourselves: **What are we trying to solve?**

A frequency problem? A dynamic problem?, a space/time problem?
