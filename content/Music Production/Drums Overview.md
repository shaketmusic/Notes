Drums come from an acoustic source or synthesis. So when we’re trying to create a certain drum sound, we should ask ourselves what types of source do we need to achieve this sound we’re looking for.

We program drums using audio or MIDI:

**Audio** – drug, drop, cut. It has advantages of independently processing the different clips, like reversing. However, it’s a lot harder to change the sound, or make macro changes, velocity.

**MIDI** – Drugging samples to a sampler. Macro changes are effortless, swing is a lot easier. You can also use generative tools.

Every method has its advantages and disadvantages, so use both.

**** Ableton adds 5 milliseconds fade to both ends of the audio clip. It can ruin your kicks.**

- **Loops** are patterns that repeat. Don’t be afraid to use loops for some of the drums, percussion.

- **One Shots** are single hits.

**How to make drum samples sound better**

**The Lin Hi Hat Trick** – instead of using the exact same sample, take an open hat and randomize the start time so they sound a little different every time. You can also connect the velocity to the decay time.

**Round Robin** – set up the sampler so that every hit triggers a different sample.


**Drum Synthesis** - A good way to learn drum synthesis is to try to copy other samples.
