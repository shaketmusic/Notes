# Startup Options

- Game Mode
    - `Project > Maps & Modes > Default Modes > Default GameMode`
- Character
    - `Project > Maps & Modes > Default Modes > Selected GameMode > Default Pawn Class`
- Maps
    - `Project > Maps & Modes > Default Maps > Editor Startup Map`
    - `Project > Maps & Modes > Default Maps > Game Default Map`
- Rendering
    - Global Illumination Method
        - `Engine > Rendering > Global Illumination > Dynamic Global Illumination Method`
            - Possible settings:
                - Lumen – Maximize visuals at the expense of performance.
                - None – Maximize performance at the expense of visuals.
                - Screen Space (Beta) – Middle ground, providing global illumination at lesser expense than Lumen.
- Packaging
    - Include multiple maps when packaging
        - `Project > Packaging > List of maps to include in a package build`
            - Add maps to the list so that they are included when packaging
    - Game Icon
        - Mac
            - `Platforms > Mac > Icon > Game Icon`

# FAQ

- Detect when sound finishes:
    - Use the `Bind Event to On Audio Finished` node. Then create a custom event to define the behavior that will be executed once the audio is finished.
- Delay function execution
    - You can use a `Delay` node, but alternatively, an event can be delayed using the `Set Timer by Function Name` node.
- Curves and lookup tables when using LERP
    - You can create a `Curve` asset to define your lookup table, and the use the `Get Float Value` node targeting the curve asset.
